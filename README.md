# Use Fulgoran Objects (U.F.O.):
## Introduction

Did you ever ask yourself if it might be possible to use the fulgoran technology — which, according to legend, must have 
been unparalleled? 

Or 

What led to their downfall, around which many rumors and vague traditions swirl[^1]?

Well, the answers to these questions await, hidden within the mysterious vault ruins. You simply need to be willing to 
dig more and deeper. But be warned and proceed with the necessary caution, or something might surface that would have 
been better left undisturbed.

## Usage

To use the Fulguran know-how, you must first research some technologies in order to make your archaeological
investigations:

![U.F.O. technology](https://github.com/xyzzycgn/ufo/blob/main/doc/ufo-technology-fe.png?raw=true)

These consist of a basic branch, with two technologies that facilitate the search for the required relics, and a 
branch with advanced technologies that utilize Fulguran know-how to improve your factory. The third branch contains 
a technology that helps to gain certain resources more efficiently.

When the optional mod [Fulgoran enemies](https://mods.factorio.com/mod/Electric_flying_enemies) is loaded, two additional 
technologies are available:

![U.F.O. technology](https://github.com/xyzzycgn/ufo/blob/main/doc/ufo-technology.png?raw=true)

Hint: It is recommended to research these **before** the advanced technologies. 😉

## Compatibility

This mod is compatible to vanilla game (= space age) and offers some changes to two (optional) mods 

- [Fulgoran enemies](https://mods.factorio.com/mod/Electric_flying_enemies)
- [Hovercrafts](https://mods.factorio.com/mod/Hovercrafts)

for better integration.
