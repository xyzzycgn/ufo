# Use Fulgoran Objects (U.F.O.):
## Introduction

Did you ever ask yourself if it might be possible to use the fulgoran technology — which, according to legend, must have 
been unparalleled? 

Or 

What led to their downfall, around which many rumors and vague traditions swirl?

Well, the answers to these questions await, hidden within the mysterious vault ruins. You simply need to be willing to 
dig more and deeper. But be warned and proceed with the necessary caution, or something might surface that would have 
been better left undisturbed.
